# heart_disease
Задание: 
Создать fastapi-приложение для вашей модели классификации и развернуть данное приложение при помощи Docker. Протестировать get запросы (направляя X-вектор переменных) и получить response в виде целевой переменной, для теста можно использовать Python/Postman.

### Создание проекта
1. Создать репозиторий на github
2. git clone ssh-ссылка
3. uv venv --python 3.12 .venv
4. uv init --python 3.12
5. uv add --requirements requirements.txt
